# nhl-scoreboard review — 2026-09-17 (main @ c63998f)

Eight subsystem reviews plus my own pass. Every item marked [V] was reproduced or traced by me;
the rest were traced by the reviewer with file:line evidence. Baseline: ruff clean, 709 passed / 4 skipped.
The documentation corrections were applied in the working tree (uncommitted); the bugs were not fixed.

## 1. Crash / restart-loop bugs (fix first)

1. [V] **`24:00` in the brightness window bricks the box.** `config/models.py:77-78` only checks `^\d{2}:\d{2}$`;
   `director/brightness.py:12` does `time(24, 0)` → ValueError. `Application.__init__` calls `director.brightness()`
   (`app.py:73`) before the web server exists, so the process dies at startup, systemd restarts it, same config,
   dies again; the UI is never up to fix it. Users type 24:00 for midnight. Fix: field validator (or pattern
   `^([01]\d|2[0-3]):[0-5]\d$`) plus a fallback to "not night" on a parse failure so an old config still boots.
2. [V] **A failed config write loses config.json.** `config/store.py:110-116` rotates backups (moving config.json to
   .1) *before* writing the temp file; ENOSPC on the temp write leaves no config.json, and the next boot writes
   defaults and reruns the wizard. Fix: write+fsync tmp first, copy (not move) current → .1, then `os.replace`.
3. [V] **Salvage throws the whole config away on a `missing` error.** `config/store.py:203-211`: a pydantic
   `missing` loc points at a leaf that does not exist, `_delete_path` returns False, nothing progresses, the file
   goes to `.broken`. One hand-edited playlist entry without `board` loses every setting. Fix: on `missing`,
   delete the parent path.
4. **A bad OTA update crash-loops forever with no way back.** Unit has `Restart=always`, `RestartSec=3`, no
   `StartLimit*`; a commit that fails at import restarts every 3 s indefinitely and nothing records the previous
   SHA. Also `updater.py:147-155` merges before pip, so a pip failure leaves the checkout advanced with old deps.
   Fix: persist the pre-update SHA under `$SCOREBOARD_DATA_DIR`, `git reset --hard` on pip failure, add a
   rollback action and/or a boot-health marker; set `StartLimitIntervalSec=60 StartLimitBurst=5`.
5. [V] **`curl … | bash` cannot elevate itself.** `install.sh:24` re-execs `sudo bash "$0"`, but `$0` is the
   literal `bash` when piped, so it fails with "bash: bash: No such file". Docs now say `| sudo bash`; the script
   should detect the pipe and die with that instruction (or re-fetch itself).
6. **A plugin source whose `run()` returns synchronously freezes the asyncio side.** `data/source.py:197-205`
   restarts a returned `run()` with no await, so nothing else on the loop runs. Bundled sources never return, so
   this is a contract hole, but the fix is one `await asyncio.sleep(RESTART_BACKOFF_SECONDS[0])`.

## 2. High: wrong things on the panel

7. [V] **Shootout shows as intermission.** `nhl/normalize.py:133`: LIVE + clock not running + `00:00` → intermission,
   which is exactly the SO clock. Boards show INT and the green bar, the state flips, `nhl.state_change` fires.
   Skip the heuristic when `periodDescriptor.periodType == "SO"`.
8. [V] **Football halftime drops the main event.** `nhl/select.py:6` has no `HALF` (priority 9) and line 21 excludes
   it from the "active game on another date" exemption. At halftime the board flips to another favourite's pregame
   card, or to nothing when local midnight has passed. Add `HALF: 0` (and `POST: 3`) and include HALF as active.
9. [V] **A two-point conversion fires a SAFETY alert.** `nfl/events.py:13` maps delta 2 → safety. Classify from
   ESPN's `lastPlay.type.text` when present; delta only as fallback.
10. [V] **Plugin settings are saved without validation, then silently discarded at runtime.** `web/api.py:171-183`
    never validates `boards.*`/`sources.*`; `effective()` masks it (`api.py:160-163`); `app.py:194-200` and
    `director.py:413-415` fall back to model defaults. Clearing the NHL live_interval box returns 200, the page
    shows it saved, and the NHL source silently forgets your favourites and follows TOR. Validate touched sections
    against the registry models and return 422.
11. [V] **Preview WebSocket reconnects forever after unmount.** `app.js:35-38`: cleanup calls `ws.close()`, `onclose`
    schedules `connect()`. Every page switch leaves a zombie socket, each making the Pi encode PNGs at full
    preview_fps. Add a `closed` flag.
12. [V] **Logos never retry after a failed first fetch.** `logos.py:136-142` re-runs `prefetch` only when the config
    generation changes; a Pi that boots before Wi-Fi is usable shows coloured discs until restart. Same shape in
    `follower.py:106-121`. Re-run on a backoff while anything wanted is missing.
13. **Rotate 90/270 in the wizard cannot work.** `output/matrix.py:44-45` derives rows/cols from the unrotated
    width/height and the director renders at the unrotated size; the mapper swaps the canvas, so SetImage clips.
    Either derive physical panel dims separately and render at `matrix.width/height`, or hide those two options.
14. [V] **A crashed NHL loop duplicates its siblings.** `nhl/source.py:85` gathers three loops; an escaping exception
    restarts `run()` without cancelling the other two, so each crash adds another standings loop + logo watcher.
    Use `asyncio.TaskGroup`.
15. [V] **Weather forecast strip uses the OS clock.** `extras/weather/board.py:128` filters on `date.today()` (UTC on
    a Pi) instead of `ctx.now`; between local evening and midnight the strip drops tomorrow. Also breaks the
    boards-are-pure rule.
16. **NFL/NCAAF never report offseason.** `nfl/source.py:180-188` derives the phase from whatever slate ESPN returns
    (next week's once a schedule exists), so `is_offseason` (needs every source) is false all summer and
    `season.countdown` never plays. Port the NCAAH rule or read `leagues[0].calendar`.

## 3. Medium

Core / director
- [V] Detectors and snapshot listeners run unisolated (`data/store.py:175`, `data/events.py:64`): a raising
  detector crashes the publishing source and skips the arbiter for that publish.
- [V] `SourceContext.sleep` clears the wake event *before* waiting (`data/source.py:691`), so a settings save
  that lands mid-fetch is lost and the source naps the whole interval.
- Board-config cache race (`director.py:142/405-418`): a save between the frame's cfg read and the cache fill pins
  the old section under the new version; "my change did nothing" until the next save.
- `board.enter()` runs outside the quarantine try (`director.py:163`); a failed sequence build replays the
  previous event's timeline for the new goal.
- `_pinned` ignores quarantine (`director.py:353`): a raising clock/splash logs an exception every frame at 30 fps.
- Only the NHL source publishes `system` (`nhl/source.py:119`); a follower publishes `online: false` after an
  outage and never `true` (`follower.py:77`), so the red dot sticks until the master relays its own system key.
- `keep_bright_when_live` tests `state == LIVE` only (`director.py:135`): the panel dims at every intermission.
- Pending events never expire (`director.py:144/335`): a goal queued behind a 60 s override plays a minute late.

Config / web / integrations
- `ConfigStore.replace` (PUT, reset, holidays save) does not guard listener exceptions and skips migration
  (`config/store.py:63-72`); a raising listener = 500 after the file is written.
- Display edits on the Settings page have no restart button (`settings.js:84`, `wizard.js:40/67`).
- Updater never reloads the page after an update (`app.js:70-87`): old JS against the new API.
- MQTT `_pending` grows without bound while disabled (`mqtt.py:80-83`); clean shutdown never publishes
  `status: offline` (aiomqtt sends DISCONNECT, so the will is discarded) — Home Assistant sees a down panel as online.
- Follower teams arriving while a logo prefetch runs are never fetched (`follower.py:117-121`).
- Restart/update waits on the follower long-poll: no `timeout_graceful_shutdown` (`app.py:142`) and
  `/api/snapshot?since=` holds up to 60 s (`api.py:233`); the wizard's restart poll then clears early.
- `updater.py`: uses `pip` (a `uv sync` venv has none) and ignores uv.lock; `check()` and `_run_update()` can run
  `git fetch` concurrently; after a pip failure the state reports "up to date".
- `RestrictRealtime=yes` in the unit strips SCHED_FIFO from the matrix refresh thread (visible flicker without
  isolcpus). `MatrixOutput.close()` only Clears, never destroys the matrix; `close()` is skipped on a non-clean exit.
- Only a cp313 rgbmatrix wheel exists: Bookworm (3.11) always builds from source and needs cmake; the `pi` extra
  marker is a silent no-op on 3.11.

Render
- [V] `Text.cache_key` uses `id(font)` (`render/layout.py:157`); fonts come from a 128-entry LRU the clock alone
  overflows, ids get reused, cached glyphs can be drawn with the wrong font.
- [V] Weighted spacers drop the remainder (`layout.py:262-268`): a row with n spacers ends up to n-1 px short
  (the game-board home logo sits 1 px off the edge on odd leftovers). Fixing shifts some goldens.
- `logos._downscale` decodes/resamples 4096 px art synchronously on the event loop (`logos.py:237`).

Sports
- NHL: landing failure replays penalty alerts and drops the PP (`nhl/source.py:149`, length-based detection
  `events.py:33`); local vs league date in `select.py:21` loses pregame/postgame east of the Atlantic; standings
  loop uses `asyncio.sleep` so a favourites change waits up to 1 h (same in nfl/ncaah/mlb/ahl); ticker freezes
  scores at enter (`ticker.py:65`); `_with_last_night` makes an extra request every poll.
- NCAAH: Stonehill is `STO` in the registry but `STONEHILL` on ESPN's scoreboard → cannot be followed
  (`ncaah/teams.py:25`); a mid-season Tuesday reads as offseason on a hockey-only box (`ncaah/source.py:89`).
- AHL: off-day ticker never shows the next slate inside the window (`ahl/source.py:118-127`).
- MLB: home runs usually arrive as plain runs because `currentPlay` has moved on (`mlb/events.py:24`).
- NFL/NCAAF: no postponed/cancelled handling (`nfl/normalize.py:93`); hockey has the NOT_PLAYED table.

Extras
- [V] Two holidays on one day: only the last name survives (`holidays/source.py:90`); 2027-12-24 is
  "Christmas Day (observed); Christmas Eve" → the observed day and its picture/override vanish.
- Alerts: a watch upgraded to a warning inherits the watch's key so no interrupt fires (`alerts/model.py:77-90`);
  chain knowledge is one fetch deep so a missed poll re-interrupts (`alerts/source.py:107`).
- Flights: overhead interrupt re-fires when an aircraft flickers out of the zone (`flights/source.py:137`);
  altitude None counts as 0 ft.
- [V] iPhone/Samsung JPEGs (Pillow format "MPO") are refused by the holiday upload (`holidays/images.py:41`).
